## Exercícios realizados

### ex01 — FocusFlow: gestor de hábitos

Aplicação desenvolvida em React para acompanhar hábitos diários. Permite adicionar hábitos, classificá-los por categoria, pesquisar, filtrar por estado, marcar hábitos como concluídos e removê-los.

O exercício foi organizado em componentes reutilizáveis (`FormularioHabito`, `Filtros` e `CartaoHabito`) e utiliza `useState`, `useMemo` e `useEffect` para gerir o estado, calcular o resumo e atualizar o título da página.

## Como executar

1. No terminal, entre na pasta do exercício: `cd ex01`.
2. Instale as dependências: `npm install`.
3. Inicie o servidor de desenvolvimento: `npm run dev`.
4. Abra o endereço indicado pelo Vite no navegador.

Para criar uma versão de produção, execute `npm run build`.
